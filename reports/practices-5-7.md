## Подтверждённые результаты

- SSH по Ed25519, порт 2222, запрет root и парольной аутентификации, UFW LIMIT.
- Восстановление от 01-clean-install за 51,4 с, успешный аудит после восстановления.
- Статический сайт HTTPS, HTTP → HTTPS 301, собственная 404, явное доверие --cacert.
- Пять сценариев deploy.sh: 0, 0, 1, 1, 1; восстановительная доставка — 0.
- Опыты с правами и подменой страницы, восстановление безопасных прав.
- Docker Engine 29.9.2, Compose v5.6.1, uid 999 у приложения, PostgreSQL healthy.
- Сохранение счётчика после down и обнуление после down -v на учебной базе.
- Публикация приложения только на 127.0.0.1:5000; база без публикации 5432.
- HTTPS-прокси /app/, отказ 502 при остановке app и успешное восстановление.
- Итоговый аудит — 14 проверок, код 0; нарушение публикации порта — код 1.
- Созданы снимки 01, 02, 03, 04-nginx-https и 05-docker-compose; VM оставлена работающей.

Прямой доступ с Windows: https://devops.local/ и https://devops.local/app/.
Сертификат самоподписанный; для curl используется открытый ~/devops.crt.
Из-за конфликта AmneziaVPN адрес 192.168.56.101 добавлен в исключения VPN.
